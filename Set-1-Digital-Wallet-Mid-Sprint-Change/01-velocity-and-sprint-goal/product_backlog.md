# Product backlog supplied for the sprint (ordered by the Product Owner)

Sample backlog prepared for this exercise.

| ID | Story | Points |
|---|---|---|
| WAL-101 | As a user I want to add money to my wallet by UPI so that I can pay from the wallet | 5 |
| WAL-102 | As a user I want to send money to another wallet user by phone number so that I can pay friends instantly | 8 |
| WAL-103 | As a user I want to see my transaction history with date and type filters so that I can check my spending | 3 |
| WAL-104 | As a user I want to set and change a 4-digit wallet PIN so that only I can make payments | 3 |
| WAL-107 | As a new user I want Rs.50 cashback on my first payment so that I try the wallet | 2 |
| WAL-108 | As a user I want a dark mode so that the app is easy on my eyes at night | 2 |
| WAL-105 | As a user I want to upload KYC documents so that my wallet limit increases | 8 |
| WAL-106 | As a user I want to pay my electricity bill from the wallet so that I don't need another app | 5 |
| WAL-110 | As a user I want a monthly statement PDF so that I have a record | 3 |
| WAL-109 | As a user I want to split a bill with friends so that we share costs easily | 13 |
